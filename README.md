# pet-react-vite-app

Приложение для создания заметок.

## Используемые технологии:
  * React, React-DOM.
  * Vite для сборки приложения.
  
## Особенности:
  ### CSS
  * Использован пакет classnames для некоторых компонентов.
  ### React Custom Hooks
  * Реализована пользовательская функция для взаимодействия с localstorage.
  
## Запуск
  * npm install
  * npm run dev
